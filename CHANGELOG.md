# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.6.4] - 2026-10-16
### Fixed
- PHP warning when a role added through `wcipc_roles` has no color.
- 1.6.3 ZIP packaged an empty main plugin file; this release replaces it.
### Changed
- Plugin URI points to the GitHub repository.

## [1.6.3] - 2026-10-16
### Changed
- Frame buttons redesigned (dark cards, role-color dot, check mark on the selected one, hover lift). Ribbon text on the card is always white; light role colors such as gold are deepened for contrast.

## [1.6.2] - 2026-10-16
### Changed
- Card artwork polished: soft feathered clouds (30% opacity), hazy layered hills with mist, landmark shadows, natural tree line, gradient ribbon, soft ring shadow with a fine white outer ring.

## [1.6.1] - 2026-10-16
### Changed
- Card maker background is `#F0FBF4`; role chips use white text on dark green.
- Title plate redesigned with a green date and venue panel.
- Soft clouds (30% opacity) added to the card sky.

## [1.6.0] - 2026-10-16
### Changed
- Card artwork redesigned after the WordCamp Islamabad 2026 poster: mint-white sky, misty green Margalla Hills, green Pakistan Monument and Faisal Mosque, forest line, green title plate.
- Interface and default colors follow the website palette (dark `#06241e`, bright green `#26d465`). Sites still on the old defaults are updated automatically.

## [1.5.3] - 2026-10-15
### Changed
- Green theme for the card maker container.

## [1.5.2] - 2026-10-15
### Changed
- Interface colors restored to the cream, green and white scheme.

## [1.5.1] - 2026-10-15
### Changed
- Card maker is up to 1280 px wide; modernised panel with sections, Auto fit switch and live zoom/rotate values.
### Fixed
- Auto fit label and Reset position button could be hidden by theme styles.

## [1.5.0] - 2026-10-14
### Changed
- Illustrated Islamabad landmarks scene is the only background; selector removed.
- Default hashtag is `#WCISB2026`.

## [1.4.0] - 1.4.1
### Added
- Faisal Mosque and Pakistan Monument SVG illustrations; redesigned title plate.

## [1.2.0]
### Added
- Event logo in the circle and badge; Auto fit option; author set to Arslan Kalwar.

## [1.1.0]
### Added
- Illustrated frame, event logo setting, per-role colors, theme-proof CSS.

## [1.0.0]
- Initial release.
