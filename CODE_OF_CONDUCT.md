# Code of Conduct

This project follows the [WordPress Community Code of Conduct](https://make.wordpress.org/community/handbook/wordcamp-organizer/planning-details/code-of-conduct/), which is based on the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, assume good intent, give and accept constructive feedback gracefully, and focus on what is best for the community. Harassment of any kind is not tolerated.

Report unacceptable behavior to akkspros@gmail.com.
